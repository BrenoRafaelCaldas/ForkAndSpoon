Imagens Regulares

- Para adicionar uma imagem regular, é necessário usar o catálogo de ativos, onde as imagens são armazenadas para fácil acesso.
- As imagens podem ser escaladas usando o atributo "resizable" e ajustadas com o modificador "scaledToFit" para manter a proporção.

Imagens do Sistema

- As imagens do sistema são fornecidas pela Apple e podem ser usadas livremente em projetos, acessíveis através do aplicativo SF Symbols.
- Modificadores como "image scale", "foreground color" e "padding" podem ser aplicados a essas imagens para personalização.

Combinação de Imagens e Texto

- É possível combinar imagens do sistema com texto, utilizando modificadores em grupo para aplicar estilos de forma eficiente.
- O uso de modificadores permite um controle detalhado sobre a apresentação das imagens e textos na interface do usuário.

|Atributo|Descrição|
|---|---|
|`resizable`|Permite que a imagem seja redimensionada para preencher todo o espaço disponível.|
|`scaledToFit`|Mantém a proporção da imagem enquanto a redimensiona para caber no espaço disponível.|
|`frame`|Define o tamanho da área onde a imagem será exibida, podendo incluir propriedades de alinhamento.|
|`imageScale`|Modifica o tamanho da imagem, permitindo que ela seja maior ou menor.|
|`foregroundColor`|Altera a cor da imagem ou do texto.|
|`background`|Define a cor de fundo da imagem ou do elemento.|
|`padding`|Adiciona espaço entre a imagem e outros elementos da interface.|
|`cornerRadius`|Define o quão arredondados serão os cantos da imagem ou do elemento.|

Esses atributos ajudam a personalizar a aparência e o comportamento das imagens em suas aplicações, permitindo uma interface mais rica e interativa.
