
Sistema de Compilação do Xcode

- O Xcode utiliza um sistema de compilação que gerencia arquivos e pastas do projeto, definindo como o projeto deve ser desenvolvido e quais dependências são necessárias.
- Ao clicar no botão "Run", o sistema de compilação é ativado automaticamente, iniciando a construção do projeto e permitindo que o aplicativo seja executado em um simulador ou dispositivo físico.

Tipos de Sistemas de Compilação

- Existem dois sistemas de compilação disponíveis no Xcode: o sistema legado, que será removido em versões futuras, e o novo sistema, que oferece melhor desempenho e confiabilidade.
- O novo sistema é capaz de identificar problemas de configuração que o sistema legado não consegue detectar.

Configurações de Compilação

- As configurações de compilação permitem controlar as fases de construção para gerar o aplicativo, sendo essencial conhecer essas configurações para resolver erros de compilação.
- A seção de arquitetura define quais tipos de dispositivos o aplicativo suportará, enquanto a seção de empacotamento permite especificar o nome do aplicativo e a seção de implantação define a família de dispositivos alvo e a versão mínima do iOS suportada.
