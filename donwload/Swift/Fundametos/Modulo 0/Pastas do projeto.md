
Estrutura do Projeto

- O projeto é organizado em uma pasta raiz, onde você pode configurar informações como nome de exibição, identificador do pacote e versão.
- Dentro da pasta raiz, há três subpastas principais: a pasta do aplicativo, a pasta de testes unitários e a pasta de testes de interface.

Pasta do Aplicativo

- Esta pasta contém os recursos principais do aplicativo, incluindo arquivos como info.plist, app delegate e storyboard para a interface do usuário.
- É o local onde você pode adicionar recursos como vídeos e imagens, além de criar a interface visual do aplicativo.

Pasta de Testes

- A pasta hello_worldTests é destinada a testes unitários, permitindo verificar funcionalidades do código.
- A pasta hello_worldUITests é usada para testar interações na interface do usuário, garantindo que o comportamento atenda aos requisitos do cliente.
