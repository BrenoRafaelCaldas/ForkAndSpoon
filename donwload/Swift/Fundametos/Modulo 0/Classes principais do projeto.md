
**Classe AppDelegate**

- A classe AppDelegate é essencial para o funcionamento do aplicativo, servindo como o ponto de entrada da aplicação.
- Quando um novo projeto é criado no Xcode, o arquivo AppDelegate.swift é gerado automaticamente, contendo código inicial que define o comportamento do aplicativo.

**Classe ViewController**

- A classe ViewController permite a interação do usuário com o aplicativo, sendo a principal interface para gerenciar as ações do usuário.
- Cada ViewController está conectado a um storyboard, que organiza a interface do usuário, permitindo uma experiência interativa.

**Estrutura do Projeto**

- O projeto gerado no Xcode contém várias pastas e arquivos, incluindo AppDelegate.swift e ViewController, que são fundamentais para o desenvolvimento de aplicativos interativos.
- O aprendizado futuro incluirá como utilizar essas classes para construir aplicativos dinâmicos e interativos.
