
- As views são os blocos de construção da UI em um aplicativo iOS, incluindo elementos como texto, imagens e botões.
- A classe UIView é a base para todas as views, gerenciando a exibição de informações e o tratamento de eventos.

Controladores de Visualização

- Os ViewControllers são essenciais, representando cada tela do aplicativo e controlando a interação do usuário, animações e navegação.
- Cada ViewController pode conter múltiplas UI components, que são instâncias de views.

Tipos Comuns de Views

- ScrollView: exibe conteúdo maior que a tela, permitindo a rolagem de outros elementos UI.
- TableView: apresenta elementos reutilizáveis em uma lista vertical, com recursos como cabeçalhos e seções.
- SplitView: organiza views lado a lado, útil para aplicativos responsivos em iPads.
