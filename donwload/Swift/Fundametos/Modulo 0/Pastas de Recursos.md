
Adicionando Arquivos ao Projeto

- Abra um projeto existente no Xcode e clique com o botão direito na pasta do projeto.
- Selecione "Adicionar Arquivos ao nome do projeto" e escolha os arquivos que deseja adicionar.

Gerenciando Arquivos

- Marque a opção "copiar itens se necessário" para garantir que os arquivos sejam copiados para o projeto.
- Verifique se os arquivos aparecem em "Copy Bundle Resources" para garantir que serão exportados com o aplicativo.
